HuntAR User Guide

A practical reference for the current HuntAR 4.3.0 field interface.

Core interface

The main HUD is organized around a live terrain view, species and location selectors, wind/time/terrain-confidence instruments, a compass, terrain-intelligence modes, a relative score legend, elevation/GPS context, a range scale and waypoint controls.

Relative score legend

High: 70–100
Strongest relative score band.
Medium: 40–69
Intermediate relative score band.
Low: 0–39
Lower relative score band.

The legend is deliberately a relative score. It is not a measured probability that an animal is physically present at that moment.

Local-first operation

Waypoints are designed to store locally first. Offline mapping and Hunt Area workflows are built to remain useful without continuous cellular service. Connected synchronization or shared functions are optional and depend on configured services.

Safety separation

Legal exclusions, access restrictions and safety layers are kept conceptually separate from wildlife/terrain scoring. A safety or legal exclusion must not be overridden because a terrain score is high.
