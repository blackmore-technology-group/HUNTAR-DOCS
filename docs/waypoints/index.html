Waypoints, Tracks & Routes

Save important field context locally and navigate without requiring a cloud account.

Local-first waypoints

The waypoint subsystem stores records on the device first. A waypoint can include a name, notes, species/mode context, geographic position where available, elevation and synchronization state.

Create a waypoint

  1. Choose Set Waypoint.
  2. Place it on terrain where spatial placement is available, or use Mark My Position.
  3. Name it and add optional notes.
  4. Save and confirm it appears in the waypoint manager.

Navigate to a waypoint

For geographic waypoints, HuntAR can calculate distance and bearing from the current position and show a navigation HUD. Heading quality and GPS accuracy affect guidance stability.

Tracks

The waypoint manager includes a track workflow for recording movement context. A saved track is a field record, not proof that the route remains legally accessible or safely passable later.

Route modes

The current route interface includes approach, stalk, observe, intercept, recovery, pack out, return and emergency exit. These modes are planning context only; they do not authorize entry onto land or guarantee safety.

Cloud synchronization

Local waypoint storage does not require a cloud account. Where synchronization/group features are configured, network services may be used for selected field context. See the Privacy Policy.
