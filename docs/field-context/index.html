Wind, Visibility & Field Context

Use the instruments together; no single sensor or overlay should carry a field decision by itself.

Wind

The HUD exposes wind context and a wind-oriented analysis mode. Wind is useful for approach planning and scent-awareness, but local terrain can create conditions that differ from a broader weather reading.

Visibility

Visibility mode is intended to support terrain and line-of-sight reasoning. Vegetation, lighting, weather and actual local obstructions can differ from the available spatial representation.

Elevation and GPS accuracy

The HUD presents elevation and GPS-quality context where available. Poor GNSS accuracy should reduce confidence in fine-grained geographic placement and waypoint/navigation decisions.

Terrain confidence

Terrain confidence describes the current spatial/terrain context, not wildlife certainty. When confidence falls, use coarser map context and independent field verification until the spatial system stabilizes.

Good practice: combine wind, visibility, terrain confidence, direct observation, map context and legal/safety checks before acting.
