Coordinated field use

Shared Field Context

Where supported and configured, HuntAR can represent peer and shared spatial context without making the network a prerequisite for core local field records.

Shared context

The HuntAR architecture includes shared spatial-world capabilities and the map renderer can display peer markers where supported. Shared context can help a group understand relative field positions, routes and waypoints.

Local-first remains primary

Waypoints and core map/navigation state are designed to work locally first. Group synchronization is an additional connected capability and should not be treated as guaranteed in remote terrain.

Network failure

If peer updates stop, assume remote positions may be stale. Do not infer another hunter's current location from an old marker when safety depends on it.

Privacy

Shared location/context can be sensitive. Use only with people you intend to coordinate with and review the Privacy Policy for connected-data boundaries.

Firearm safety: a peer marker is not a substitute for positive visual identification of people, animals, structures or what lies beyond a target.
