Release Notes

Public-facing release history for HuntAR. Internal engineering history is broader than the App Store release record.

4.3.0 · iOS build 430

Current App Store submission line · October 2026

  • Native iOS App Store packaging/signing path.
  • ARKit + Metal spatial runtime integration.
  • BSIE 2.3 mobile spatial integration.
  • NIKI mobile runtime binding.
  • Local-first waypoint/navigation subsystem.
  • Offline Hunt Area and current/historic trail map workflows.
  • Privacy manifest and export-compliance preparation.
  • Optional ENTITY native client for governed provenance workflows.

Earlier engineering releases

Prior HuntAR engineering versions developed the reference-locked HUD, terrain-following score geometry, Region 8 field/data workflows, wildfire-wildlife context, trail intelligence, shared spatial world integration and production-hardening work that fed the current mobile line.

Availability and App Store status can change independently of this page. The version shown inside the installed application is the authoritative version for that installation.
