Getting Started

Set up the app before entering the field so the features you depend on are available offline.

Before you leave coverage

  1. Install and open HuntAR. Confirm the app launches and the terrain HUD is responsive.
  2. Grant required permissions. Camera, motion/heading and precise location while using the app support AR alignment and navigation.
  3. Install the Hunt Area you plan to use. An offline Hunt Area can carry regional terrain/map context.
  4. Open the offline map. Confirm the Hunt Area, trail layers and your GPS position render locally.
  5. Create a test waypoint. Verify you can save, list and navigate to it.
  6. Confirm a species profile. Select the intended species before interpreting terrain scores.
Do not make the phone your only navigation or emergency system. Carry appropriate backup navigation, power and emergency equipment.

Offline Hunt Areas

HuntAR can install Hunt Area packages and activate the smallest matching installed area for the current GPS position. The location panel reports GPS state, active area, terrain data and legal-layer availability.

Before relying on an area offline, open it while connected and verify that the expected map and layers are present.

Select a species

Changing species resets the active terrain-scoring context and rescans visible terrain. See the Species Profiles page for the current catalogue.

First field session

Start with the 2D map to establish location and Hunt Area context. Then open the AR terrain view and allow the device to obtain a stable spatial pose. Use terrain confidence as context, not proof that a wildlife prediction is correct.

Recommended workflow: map context → legal/access check → species selection → AR scan → inspect one layer at a time → save relevant waypoints → independently verify conditions.
