Support

Troubleshooting and support for the current HuntAR mobile release.

Before reporting a problem

  1. Record the HuntAR version and iOS version.
  2. Record the device model.
  3. Note whether the issue occurred online or offline.
  4. For map/AR problems, note GPS accuracy and terrain-confidence state if visible.
  5. Write the shortest reproducible sequence of steps.

Common problems

AR overlay is unstable or offset

Reduce reliance on precise placement, allow ARKit to relocalize, verify location/heading quality and use the 2D map until alignment stabilizes.

Offline map is missing expected information

Confirm the correct Hunt Area is installed and active. Data availability depends on the pack and whether it was refreshed before leaving coverage.

Waypoint has no navigation bearing

A geographic latitude/longitude is required for distance/bearing navigation. Screen-context-only records cannot provide geographic guidance.

A species cannot be selected

The UI only enables installed/available profiles. Waterfowl is currently shown as unavailable pending its dedicated waterway addition.

Report an issue

HUNTAR-DOCS issues BTG website

Do not post private keys, credentials, ENTITY bindings, precise private-location history or other sensitive information in a public issue.
