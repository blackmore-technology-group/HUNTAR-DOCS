Offline field operation

Offline Maps & Hunt Areas

Prepare the map before leaving service and verify the data you expect is actually installed.

What the offline map can show

The current map renderer is designed to combine local Hunt Area content with GPS, waypoints, routes, tracks and trail context. Depending on the installed pack and datasets, features can include terrain/vegetation context, water, roads, trails, hunting-zone context, property/access information, legal exclusions and user exclusions.

Current and historic trails

The map provides separate toggles for current trails and historic trails. Historic or legacy lines may represent abandoned, overgrown, relocated or impassable routes. A line on the map is not a promise that a trail is safe, open or physically present.

Hunt Area activation

The location panel is designed to activate the smallest matching installed Hunt Area using the current GNSS fix. It reports whether an offline area, terrain data and legal layers are available.

Map controls

  • Zoom and pan the local map.
  • Center on current GPS position.
  • Toggle current and historic trails.
  • View waypoints, routes, tracks and peer markers where supported.
  • Reload navigation context when field state changes.

Offline verification

  1. Install the correct Hunt Area.
  2. Open the area and verify expected data while connected.
  3. Remove data service or use airplane mode.
  4. Confirm the map, GPS, waypoint list and required layers still function.
  5. Carry an independent backup map/navigation method.
Offline does not mean authoritative. Downloaded information can become stale. Closures, regulations, wildfire conditions, private access and road/trail conditions can change after a pack is installed.
