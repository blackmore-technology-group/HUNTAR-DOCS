# HUNTAR-DOCS

Official public documentation for **HuntAR** by Blackmore Technology Group Limited.

Live site: https://blackmore-technology-group.github.io/HUNTAR-DOCS/

Includes getting started, full user guide, AR terrain intelligence, offline maps, waypoints/routes, species, safety/legal boundaries, architecture, privacy, support, FAQ and release notes.

Public documentation intentionally excludes private keys, credentials, proprietary model internals, production ENTITY bindings and security-sensitive material.
