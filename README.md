# HUNTAR-DOCS

## HuntAR and the BTG Universal Technology Foundry

HuntAR is a **native iOS geospatial application** and a demanding real-world acceptance project for the unified Foundry. Its intended app functionality includes camera and AR terrain overlays, species selection, GPS/heading, 2D maps, offline geospatial data and legal/safety boundaries. BTG Studio, NIKI, DataChips, BSIE, ADAM/BTDU and ENTITY share the Foundry infrastructure for designing, repairing, independently verifying and deploying such applications.

An architecture description is not evidence that HuntAR's current native build has passed those acceptance tests. The [BTG engineering evidence register](https://www.blackmoretechgroup.com/engineering-proof.html) describes the required real-device qualification, with the [one-platform architecture](https://www.blackmoretechgroup.com/platform-architecture.html) defining the integration boundaries.


Official public documentation for **HuntAR** by Blackmore Technology Group Limited.

Live site: https://blackmore-technology-group.github.io/HUNTAR-DOCS/

Includes getting started, full user guide, AR terrain intelligence, offline maps, waypoints/routes, species, safety/legal boundaries, architecture, privacy, support, FAQ and release notes.
